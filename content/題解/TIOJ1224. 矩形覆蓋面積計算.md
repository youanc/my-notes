## 題目大意

給定 $n$ 個矩形，第 $i$ 個矩形的四個邊分別為 $l[i],u[i],r[i],d[i]$ ，問所有矩形在平面上的總覆蓋面積。

$1<=n<=1e5$  
$0<=l[i],u[i],r[i],d[i]<=1e6$  

## 解題思路

### 離散化

$1e6$ 這種數字很尷尬不知道會不會記憶體爆炸然後 $RE$ ，所以我先離散化，至於長度的話就是之後記得計算的時候對回去原本的座標。

### 掃描線與線段樹

遇到這種二維問題我們都先轉換回一維來想想看，如果今天是一維的話就等於是很多區間取聯集長度，如果真的就是一維那就 $bitset$ 暴力解決，不過多一個維度的話，區間就有**時效性**了， 我們考慮由下往上的掃描線，這時區間會從矩形底部進入，矩形頂部離開，所以我們需要一個能夠動態維護區間進出的結構，很顯然就是用我們最喜歡的線段樹。

### 解法一

這個解法我自己是沒實作，簡單來講就是，既然要對區間進行修改那肯定就是第一個想到 $Lazy\ Tag$ ，存的東西比較需要想一下，首先，我們需要的資訊就是當前的區間聯集長度，既然是聯集長度，不妨反過來想，算 $0$ 有幾個，因為線段樹中的值肯定非負，所以我們只要知道全域最小值，如果是 $0$ ，再透過 $0$ 的個數扣掉就好，所以這邊線段樹要維護的就是最小值以及最小值的個數，最後加一加就好。

順帶一提，如果線段樹要同時維護兩種相依的值那就別分開寫，舉例來說，這邊要維護的是最小值及個數，所以在查詢個數時我們會需要知道左右子節點的最小值，這時如果分開寫兩個 $query$ 函數就會發生多一個 $log$ 的災難。

### 解法二

這個解法我個人覺得比較酷，就是我們直接不用 $Lazy\ Tag$ ，因為這種掃描線有一個性質：

- 一個區間進入的話，一定會在未來有個一模一樣大小的區間離開，也就是說他有對稱性，區間不會被切開，也就不需要下推標記。  

- 我們只需要根節點的資訊，也就是說不會有需要單獨查詢沒出現過的區間節點的狀況。  

所以呢，我們先令 $cnt[id]$ 表示這個節點區間被完全覆蓋幾層，$len[id]$ 表示這個節點被覆蓋的總長度。這時候如果 $cnt$ 非零就直接拿原座標左右界相減的長度就好，反之就遞迴下去問子節點，$len[id]=len[lc]+len[rc]$ 。

這邊有個地方要小心就是線段樹陣列大小其實應該開 $8N$ ，因為 $n$ 個矩形的左右界加起來會有 $2n$ 個， 還有一點是，注意線段樹每個節點代表的是一個**區間**，跟一班我們用點去存不太一樣，在 $update$ 跟曲區間長度的時候左右界要注意一下。

## AC 程式碼

```cpp
#include <bits/stdc++.h>

using namespace std;

using ll=long long;

using pii=pair<int,int>;

#define F first

#define S second

#define all(x) x.begin(),x.end()

const int N=1e5+14;

#define lc id<<1

#define rc (id<<1)|1

vector<int> xs;

struct SEG{

    int len[8*N],cnt[8*N];

    void pull(int l,int r,int id){

        if(cnt[id]){

            len[id]=xs[r+1]-xs[l];

        }else{

            if(l==r) len[id]=0;

            else len[id]=len[lc]+len[rc];

        }

    }

    void upd(int l,int r,int ql,int qr,int id,int val){

        if(ql<=l&&r<=qr){

            cnt[id]+=val;

            pull(l,r,id);

            return;

        }

        int mid=l+(r-l)/2;

        if(ql<=mid) upd(l,mid,ql,qr,lc,val);

        if(qr>mid) upd(mid+1,r,ql,qr,rc,val);

        pull(l,r,id);

    }

}seg;

int l[N],r[N],d[N],u[N];

struct event{

    int le,ri,y,type;

    bool operator<(const event &e){

        return y<e.y;

    }

};

vector<event> ev;

signed main(){

    ios::sync_with_stdio(0),cin.tie(0);

    int n;cin>>n;

    for(int i=1;i<=n;++i){

        cin>>l[i]>>r[i]>>d[i]>>u[i];

        xs.push_back(l[i]);

        xs.push_back(r[i]);

    }

    sort(all(xs));

    xs.resize(unique(all(xs))-xs.begin());

    for(int i=1;i<=n;++i){

        l[i]=lower_bound(all(xs),l[i])-xs.begin();

        r[i]=lower_bound(all(xs),r[i])-xs.begin();

        ev.push_back({l[i],r[i],d[i],1});

        ev.push_back({l[i],r[i],u[i],-1});

    }

    sort(all(ev));

    int prev=0;

    ll ans=0;

    for(auto[le,ri,y,type]:ev){

        ans+=1ll*(y-prev)*seg.len[1];

        if(le<ri) seg.upd(0,xs.size()-2,le,ri-1,1,type);

        prev=y;

    }

    cout<<ans<<'\n';

}
```
