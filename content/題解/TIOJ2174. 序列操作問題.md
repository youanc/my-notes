## 題目大意

有一個長度為 $N$ 的序列 $A$ ，一開始 $A[0],A[1],...,A[N-1]$ 都是 $0$ 。接下來有 $M$ 個操作，每個操作間隔一單位時間，操作分為以下兩種：

- 把某個區間的每個數都加上 $x$ ，其中 $x \in \{\pm1\}$ 。  
- 給定 $k$ ，問從詢問開始到現在有多少單位時間 $A[k]=0$ 。

$1<=N,M<=3e5$  
保證操作過程中 $A$ 中所有元素非負  

## 解題思路

可以發現他操作是對 $A$ 的區間，但詢問是對時間區間，所以我們其實可以把它想像成一個二維問題，之後對其中一維排序做掃描線之類的。直覺上我們都是依照時間順序去做事，不過在這題對時間做掃描線之後對空間開線段樹沒什麼好性質。

但換個角度想，如果我們是對空間做掃描線，也就是從 $A[0]$ 掃到 $A[n-1]$ ，好像就有好性質可以運用了。想像把所有操作的左右界搜集起來並排序，我們從左往右掃，掃到第 $i$ 項的時候，他和第 $i-1$ 項差異只會有以 $i-1$ 為右界還有以 $i$ 為左界的操作，整個掃下去加起來也只有 $2M$ 個修改。

至於要修改什麼，就直接在時間軸對後綴做區間改值就好，在線段樹上維護做小值以及最小值的數量即可，複雜度就會是良好的 $O(MlogN)$ 。

### 標記永久化

雖然這題用一般的 $Lazy\ Tag$ 就好，不過因為這題有個好性質：

- 標記有交換律，先後順序交換不會怎樣。  

所以有一個小技巧可以用，我們先令 $tag[id]$ 為這個區間被完全覆蓋的次數， $mn[id]$ 為區間最小值， $cnt[id]$ 為區間最小值個數（一開始記得初始化為區間長度），我們可以不做標記下推跟重置，只需要在改值的時候每次遞迴完左右子節點記得 $pull$ 。如果區間已經被完全覆蓋就直接改 $tag$ 跟自己的 $mn$ 就好，否則就合併子節點資訊。

最後是 $query$ 的部分，因為是永久化標記沒有下推，所以要多傳一個參數來存祖先下來的一路上累積的標記，這樣算出來才會是正確的答案。

注意，時間長度是區間，但是我們每個事件都是在點上，所以左右界要想清楚。

## AC 程式碼

```cpp
#include <bits/stdc++.h>

using namespace std;

using pii=pair<int,int>;

#define lc id<<1

#define rc (id<<1)|1

#define all(x) x.begin(),x.end()

const int N=3e5+14;

int n,m;

struct event{

    int pos,val,type;

};

vector<event> ev[N];

vector<pii> ans; //id,val

struct SEG{

    int mn[8*N],cnt[8*N],tag[8*N];

    void build(int l,int r,int id){

        if(l==r){

            cnt[id]=1;

            return;

        }

        int mid=l+(r-l)/2;

        build(l,mid,lc);

        build(mid+1,r,rc);

        cnt[id]=cnt[lc]+cnt[rc];

    }

    void pull(int id){

        int mn_=min(mn[lc],mn[rc]);

        cnt[id]=0;

        if(mn[lc]==mn_) cnt[id]+=cnt[lc];

        if(mn[rc]==mn_) cnt[id]+=cnt[rc];

        mn[id]=mn_+tag[id];

    }

    void upd(int l,int r,int ql,int qr,int id,int val){

        if(ql<=l&&r<=qr){

            mn[id]+=val;

            tag[id]+=val;

            return;

        }

        int mid=l+(r-l)/2;

        if(ql<=mid){

            upd(l,mid,ql,qr,lc,val);

        }

        if(qr>mid){

            upd(mid+1,r,ql,qr,rc,val);

        }

        pull(id);

    }

    int query(int l,int r,int ql,int qr,int id,int atag){

        if(ql<=l&&r<=qr){

            if(mn[id]+atag==0) return cnt[id];

            return 0;

        }

        int mid=l+(r-l)/2;

        int res=0;

        if(ql<=mid) res+=query(l,mid,ql,qr,lc,atag+tag[id]);

        if(qr>mid) res+=query(mid+1,r,ql,qr,rc,atag+tag[id]);

        return res;

    }

}seg;

signed main(){

    ios::sync_with_stdio(0),cin.tie(0);

    cin>>n>>m;

    seg.build(1,m,1);

    for(int i=1;i<=m;++i){

        int tmp;cin>>tmp;

        if(tmp==1){

            int l,r,x;cin>>l>>r>>x;

            ++l;++r;

            ev[l].push_back({i,x,1});

            ev[r+1].push_back({i,x,-1});

        }else{

            int x;cin>>x;

            ++x;

            ev[x].push_back({i,x,0});

        }

    }

    for(int i=1;i<=n;++i){

        for(auto[pos,val,type]:ev[i]){

            if(type==0){

                int an=seg.query(1,m,1,pos-1,1,0);

                ans.push_back({pos,an});

            }else{

                seg.upd(1,m,pos,m,1,val*type);

            }

        }

    }

    sort(all(ans));

    for(auto[a,b]:ans) cout<<b<<'\n';

}
```
